# 🕌 Islamic Content API

Comprehensive Islamic Content API - Authentic Hadith and Tafsir in JSON format with automatic updates for Islamic applications

## 📖 Description

A comprehensive collection of Islamic content in JSON API format including:

• **Authentic Hadith** from the Six Books (Bukhari, Muslim, Abu Dawood, Tirmidhi, Nasai, Ibn Majah)
• **Quran Tafsir** from trusted sources
• **Advanced indexing** and search capabilities
• **Automatic updates** every 6 hours
• **Multi-language support** (Arabic & English)

## ✨ Features

- 🆓 **100% Free API**
- 🌐 **Reliable hosting** via GitHub Pages
- ⚡ **Global CDN** for fast access
- 🔄 **Automatic updates**
- 📚 **Comprehensive documentation**
- 🔍 **Search and filtering support**
